Does manager overlap predict returns?

Each month the test picks the 25 most-held stocks (overlap), the stocks most added to (flow), or both, using only holdings that were already public. It holds them for 21, 63 or 126 trading days and compares them with the average of all stocks the funds hold.

How to read it: a t-statistic above 2 is the usual bar. Rank correlation near zero means a higher score does not reliably mean a higher return among the stocks. The funds were chosen because they did well recently, which flatters the early periods. Windows overlap, so the t-statistic uses non-overlapping months. The record is short, and stocks that were delisted are missing.
